# Changelog

Versions follow semantic versioning. A major version changes the ranking or turns rules on or off in a way that changes existing results, a minor version adds rules or fixes, and a patch version corrects a rule's pattern or wording.

## 1.0.0 (2026-11-05)

- First version: Vale styles for House, Oxford, NYT, AP, Chicago, and Apple rules, the vendored Red Hat and Microsoft styles, the domain ranking, a fixer for Vale's replace and edit actions, and a Claude Code hook.
