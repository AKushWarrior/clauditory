# Changelog

Versions follow semantic versioning. A major version changes a rule's outcome in a way that alters existing text, a minor version adds or deepens rules, and a patch version fixes wording without changing a rule.

## 1.1.1 (2026-11-08)

- Reword three rules so the skill passes its own linter: one action as a plain sentence, `Optional:` and `Run:` in code formatting, and the code-block introduction without a contrast formula.

## 1.1.0 (2026-11-05)

- End the revision pass by running the writing-style skill's linter, with `--commit` for commit messages.

## 1.0.0 (2026-11-05)

- First version as its own skill, split from section 9 of writing-style 1.3.0.
- Add rules from the IBM Style Guide, the Red Hat Technical Writing Style Guide, and the New Oxford Style Manual on procedures, modal verbs, identifiers, code blocks, error messages, headings, links, and dates in technical text.
